# 💬 お悩み相談室 (Onayami-Soudanshitsu)

子育てや家庭学習に悩む保護者に寄り添い、今日から実践できる小さな工夫を一緒に見つける対話型AI相談アプリです。  
Streamlit と Google GenAI SDK (`google-genai`) を用いて構築されており、幸福学・脳科学・認知心理学の知見と、実運用に耐えうるAIガバナンス（安全策・エスカレーション・監査ログ機能）を統合しています。

---

## ✨ 主な特徴・機能

### 1. 科学的知見の内面化と「一緒に作戦を立てる（We Do）」対話設計
* **マルチモーダル知識参照**: 同階層に配置された3つの専門PDF（幸福学・脳科学・学習科学）を `types.Part.from_bytes` で直接読み込み、表や構造を保ったまま対話に活用します。
* **1問1答のカウンセリング形式**: 最初から一方的に解決策を指示（Telling）するのではなく、まず保護者の気持ちを受容（バリデーション）し、1回の返答につき質問を1つだけ投げかけて状況を整理します。
* **専門用語と日常比喩のペアリング**: 資料の存在をメタ発言として出さず、専門用語（ワーキングメモリ、流暢性の錯覚、想起練習など）を使う際は必ず平易な比喩とセットで解説します（1回につき最大1〜2個まで）。
* **「📝 今日の作戦メモ（If-Thenプラン）」自動抽出**: 対話の着地点として「もし〇〇なら、△△する」という具体的な行動計画（If-Thenプラン）がまとまると、左サイドバーに自動で抽出・記録されます。

### 2. 日本標準時（JST）連動のコンテキスト配慮
サーバー時刻を日本標準時（`Asia/Tokyo`）に設定し、相談時間帯の脳のコンディションや意志力（ウィルパワー）に合わせた声かけを行います。
* **朝〜午前（5:00〜10:59）**: 意志力が満タンな時間帯を活かした重要課題への着手（ハードスタート等）を提案。
* **日中（11:00〜16:59）**: 行き詰まりをほぐす休憩（拡散モード）や、日常の小さな幸せを味わう習慣（セイバリング）を提案。
* **夕方〜夜（17:00〜21:59）**: 結果ではなく取り組みの過程（プロセス）の承認や、就寝前の2分間回想を提案。
* **深夜（22:00〜4:59）**: 難しい反省会や詰め込みを避け、記憶の定着と脳内老廃物除去のための十分な睡眠を最優先で促す。

### 3. AIガバナンスと安全設計（Human-in-the-Loop）
* **事前ガードレールと役割の明示**: チャット上部に個人情報（実名・学校名・クラス等）の入力防止ルールと、AIが「初期スクリーニング（壁打ち相手）」であることの境界線を明示しています。
* **委任禁止領域（Never-Delegate）の自動検知とエスカレーション**: 医療・発達診断、深刻なメンタル不調、不登校・いじめ・自傷などの高リスクキーワードを検知した際、AIによる独断を止め、人間の専門窓口（担当：櫻井 `k.sakurai@aiwa-learning.com`）へ即座に案内します。
* **運用テレメトリと事後監査ログ（分母除外なし）**: 正常応答だけでなく、エラー・未解決・高リスク判定・保護者からの評価（👍/👎）をすべて分母から除外せずに記録し、管理者メニューからCSV（BOM付きUTF-8）でダウンロード可能です。
* **マルチモデル自動フォールバック**: `gemini-3.5-flash-lite` / `gemini-3.8-flash` / `gemini-3.1-pro` に対応し、API利用上限（HTTP 429）やサーバー混雑（HTTP 503）が発生した際は自動で予備モデルへ切り替えます。
