# 💬 お悩み相談室 (Onayami-Soudanshitsu)

子育てや家庭学習に悩む保護者に寄り添い、今日から実践できる小さな工夫を一緒に見つける対話型AI相談アプリです。  
Streamlit と Google GenAI SDK (`google-genai`) を用いて構築されており、幸福学・脳科学・認知心理学の知見と、コードレベルで組み込まれたAIガバナンス（2段階の個人情報ブロック・呼称統一フィルター・エスカレーション・監査ログ機能）を統合しています。

## ✨ 主な特徴・機能

### 1. 科学的知見の内面化と「一緒に作戦を立てる（We Do）」対話設計
* **マルチモーダル知識参照**: 同階層に配置された3つの専門PDF（幸福学・脳科学・学習科学）を `types.Part.from_bytes` で直接読み込み、表や構造を保ったまま対話に活用します（`system_instruction` 不使用）。
* **1問1答のカウンセリング形式**: 最初から一方的に解決策を指示（Telling）するのではなく、まず保護者の気持ちを受容（バリデーション）し、1回の返答につき質問を1つだけ投げかけて状況を整理します。
* **全員「さん」付け統一 ＆ 性別確認ルール**:
  * **呼称の統一**: 性別にかかわらず「〜くん」「〜ちゃん」「〜君」は一切使用せず、すべて「お子さん」（または仮名の場合は「〇〇さん」）と「さん」付けで統一します。毎ターンのプロンプトリマインダー（`TURN_REMINDER`）に加え、Python側の正規表現フィルター（`enforce_san_honorific`）で出力テキストをリアルタイム変換する二重構造を採用しています。
  * **性別の確認**: 文脈から男の子か女の子か判断がつかない場合は、初回の聞き取り時に「確認ですが、お子さんは男の子でしょうか、女の子でしょうか？」と確認します。
* **専門用語と日常比喩のペアリング**: 資料の存在をメタ発言として出さず、専門用語（ワーキングメモリ、流暢性の錯覚、想起練習など）を使う際は必ず小学生でもイメージできる日常の比喩とセットで解説します（1回につき最大1〜2個まで）。
* **「📝 今日の作戦メモ（If-Thenプラン）」自動抽出**: 対話の着地点として「もし〇〇なら、△△する」という具体的な行動計画（If-Thenプラン）がまとまると、左サイドバーに自動で抽出・記録されます。

### 2. 日本標準時（JST）連動のコンテキスト配慮
サーバー時刻を日本標準時（`Asia/Tokyo`）に設定し、相談時間帯の脳のコンディションや意志力（ウィルパワー）に合わせた声かけを行います。
* **朝〜午前（5:00〜10:59）**: 意志力が満タンな時間帯を活かした重要課題への着手（カエルを食べる／ハードスタート法等）を提案。
* **日中（11:00〜16:59）**: 行き詰まりをほぐす休憩（拡散モード）や、日常の小さな幸せを5分間味わう習慣（セイバリング）を提案。
* **夕方〜夜（17:00〜21:59）**: 結果ではなく取り組みの過程（プロセス）の承認や、就寝前の2分間回想を提案。
* **深夜（22:00〜4:59）**: 難しい反省会や詰め込みを避け、記憶の定着と脳内老廃物除去のための十分な睡眠（7〜9時間）を最優先で促す。

### 3. AIガバナンスと安全設計（Policy-as-Code / Human-in-the-Loop）
* **2段階の個人情報（実名・学校名）ブロック機構**:
  1. **第1段階（API送信前の正規表現ブロック `check_personal_info`）**: 「〇〇小学校」「〇年〇組」「小5の〇〇」「〇〇の母/父」「〇〇くん/ちゃん/さん」などのパターンを検知し、Gemini APIへ送信する前にブロックして警告を表示します。
 <img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/f56bd199-c013-4d5d-95ff-b2ccf91f7d2f" />

     
  2. **第2段階（AI文脈検知による自動ロールバック `【個人情報ブロック】`）**: 事前フィルターをすり抜ける形で実名が入力された場合でも、AIが実名と判定した時点で画面上の発言と応答を即座に消去（ロールバック）し、履歴に残さず再入力を促します。
* **委任禁止領域（Never-Delegate）の自動検知とエスカレーション**: 医療・発達診断、深刻なメンタル不調、不登校・いじめ・自傷などの高リスクキーワード（`HIGH_RISK_KEYWORDS`）を検知した際、AIによる独断を止め、単一の最終責任者である人間の専門窓口（担当：櫻井 `k.sakurai@aiwa-learning.com`）へ即座に案内します。

* <img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/859f48e1-7bc8-4287-ad7e-ec526fdedc69" />

* **運用テレメトリと事後監査ログ（分母除外なし）**: 正常応答だけでなく、個人情報ブロック（`Blocked_PII` / `Blocked_PII_by_AI`）・APIエラー・高リスク判定・保護者からの評価（👍/👎）をすべて分母から除外せずに記録し、管理者メニューからCSV（BOM付きUTF-8）でダウンロード可能です（ブロックされた入力の本文は監査ログ上でも自動マスキングされます）。

* <img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/da679365-cbeb-4215-972f-3f564c64ce20" />

* **マルチモデル自動フォールバック**: `gemini-3.5-flash-lite`（初期値） / `gemini-3.8-flash` / `gemini-3.1-pro` に対応し、API利用上限（HTTP 429）やサーバー混雑（HTTP 503）が発生した際は自動で予備モデルへ切り替えます。
